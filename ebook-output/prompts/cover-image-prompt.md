# コンポジション
テキストコンポジション:
- タイトルとサブタイトルは上部ゾーンに配置し、図形エリアと明確に分離する。
- タイトルゾーンは白いカードのようなパネルに載せて、整理された教材らしい印象を作る。
- テキストは中央揃えまたは左寄せで、学習の進行を自然に見せる。

ビジュアルコンポジション:
- メインビジュアルは、基礎から MCP へ向かう 6 段階のカード群を縦に並べた構造にする。
- 各カードは角丸矩形で、軽い矢印や小さな点線で接続する。暗い背景や派手なグローは避ける。
- 背景は薄いグリッド線と余白を使い、教材らしい構造性を出す。
- レイアウトは上部 20% をテキスト、下部 80% を学習構造に割り当てる。

カラースキーム:
